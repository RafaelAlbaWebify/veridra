# VERIDRA functional audit — Batch 09: Proposals, deals, backup/recovery and schema

Date: 2026-10-17; source uploaded ZIP baseline, potentially outdated. **Eight modules, 1,356 lines:** `agency_proposal_artifact_web.py`, `agency_proposal_transition_web.py`, `deal_lifecycle.py`, `tenant_deal_store.py`, `backup_restore.py`, `recovery_readiness.py`, `sqlite_schema_versions.py`, `sqlite_session_manager.py`. Reviewed proposal status transitions, customer and lead side effects, store failures, backup manifest and restore transaction, migration atomicity and session rotation.

## Findings
- **F57 P1 — Accepted proposal persists before customer creation.** `agency_proposal_transition_web.py:174-251` saves deal's new `accepted` status, then calls `_ensure_customer_on_acceptance` and `_sync_next_action`. A later error leaves deal accepted without guaranteed customer/link state. Add durable reconciliation or transactional outbox; do not roll back documented external acceptance.
- **F58 P1 — Invalid persisted deal is treated as empty.** `tenant_deal_store.py:22-27` catches *all* `DealStoreError` including malformed/unreadable existing files from `deal_lifecycle.py:168-173`; UI may create new version without surfacing old commercial record. Distinguish not-found from corruption, no data deletion.
- **F59 P1 — Deal file update has no concurrency precondition.** `deal_lifecycle.py:175-195` atomic temp/replace prevents partial files but not conflicting proposals saved concurrently; missing revision check may lose acceptance evidence.
- **F60 P1 — Restore rollback/cleanup after partial failure requires fault injection.** `backup_restore.py:273-391` stages identity, email and tenant targets and attempts to restore old state on exception, but rollback `_restore_previous` is sequential. A failure during later reversal may leave mixed generations; `finally` cleanup behavior must be tested with interrupted filesystem operations. This is **risk** not observed loss.
- **F61 P2 — Migration version checks record presence, not code compatibility.** `sqlite_schema_versions.py:54-89` skips existing integer versions without verifying stored migration `name` or implementation checksum. Reused/revised version could be silently accepted; enforce immutable migration identity if schema evolves.
- **F62 P2 — Backup preflight cannot attest live writer quiescence.** `backup_restore.py:273-295` accepts `confirm_quiesced` boolean from caller. This is an explicit operational gate, but not independent proof that web/workers are stopped. Retain manual controls and verify launcher process isolation.
