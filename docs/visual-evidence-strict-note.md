# Strict visual outreach evidence

The first visual evidence run proved that element-only crops and generic accessibility-name findings are not strong enough for owner-facing outreach. The strict generator now requires contextual screenshots and promotes only visibly understandable issues: a visible link leading to a dead end, genuine mobile overflow, or a visibly blank/unexplained form field. Technical-only findings remain in the audit evidence and are not promoted into the outreach pack.
