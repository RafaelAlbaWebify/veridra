# Repository File Map

## Read first
- `.ai/` — canonical AI project-control bootstrap.
- `README.md` — product boundary, implemented capabilities and deployment gap.
- `pyproject.toml` — package metadata, dependencies, CLI entrypoints, test/lint/type configuration.
- `.github/workflows/ci.yml` — authoritative CI gate composition.

## Source
- `src/veridra/` — main Python package.
  - assessment/evidence: `core.py`, `audit.py`, crawler/safety/SEO/accessibility/trust/security-related modules;
  - agency/commercial UI: `agency_*_web.py` plus compatibility web routers;
  - identity/runtime: identity/session/signup/invitation/runtime modules;
  - billing: subscription authority, Stripe adapter/webhooks/CLI;
  - monitoring/reporting: monitoring service/worker/schedule, report/profile/delivery/comparison modules;
  - operations: backup/restore, ops checks, production preflight, deployment acceptance, access logging, tenant offboarding.

## Tests and acceptance
- `tests/` — pytest unit/integration/regression tests.
- `tools/browser_audit.py` — Chromium browser audit.
- `tools/commercial_acceptance.py` — commercial workflow acceptance.
- `tools/sales_contract_acceptance.py` — sales-to-contract Playwright acceptance.
- `scripts/browser/` — browser workflow acceptance scripts.
- `VERIDRA_OPERATOR_E2E_ACCEPTANCE.bat` — supported Windows operator E2E launcher.
- root `VERIDRA_*.bat` files — supported Windows operator/setup/acceptance helpers.

## Operations/deployment
- `Dockerfile`, `.dockerignore` — provider-neutral non-root container foundation.
- `deployment/` — deployment assets/config examples.
- `docs/operations/` — production deployment, single-host deployment, SMTP/signup, Stripe billing, backup/restore, monitoring/alerting, security headers, access logging, tenant offboarding, preflight/deployment acceptance.

## Documentation
- `docs/` — design/operations/reference material.
- `docs/modules/*.CONTRACT.md` — logical workstream contracts introduced by AI-control migration.

## Generated/runtime artifacts
- `artifacts/` is generated by acceptance/CI and should not be treated as source-of-truth unless linked to a specific run/commit.
- local SQLite/tenant state is runtime data, not source.

## Future AI loading rule
Start with `.ai/`; then open only the module contract, relevant source files, tests and deeper docs needed for the active objective. Do not load the entire repository by default.
