# Shadow Presence Care Delivery — Ballincollig Dental Practice

Status: NO CONTACT / NO CHANGE / INTERNAL SHADOW ONLY

## Baseline
- Website and online booking journey are functional.
- Human review confirmed materially conflicting opening-hours information within the website.
- Current Google/Maps evidence observed during review did not cleanly match the website schedule.
- Booking portal reaches service/practitioner/date-time/patient-details stages and displays a €50 deposit requirement.
- No personal data or payment was submitted.

## Validated customer-facing findings

### 1. Conflicting opening hours on the same website
**Evidence:** Contact page publishes Mon–Wed 08:00–20:00, Thu–Fri 09:00–17:30, Sat 09:00–13:00; footer publishes Mon–Fri 09:00–17:30 and weekend closed.  
**Impact:** patients can receive materially different availability information depending on page.  
**Class:** activation.  
**Recommended action:** obtain the canonical schedule from the owner, update all site locations, then verify.

### 2. Cross-channel business-hours uncertainty
**Evidence:** reviewed Google/Maps hours did not cleanly align with all website schedules.  
**Impact:** inconsistent local-business information can create patient friction and reputational/local-search problems.  
**Class:** activation + monitor monthly.  
**Recommended action:** owner-confirm one canonical schedule, reconcile website + Google Business Profile + booking system where applicable.

### 3. Booking journey is functional but external
**Evidence:** booking flow reaches appointment selection and patient-details stage and indicates a deposit.  
**Impact:** positive conversion capability; dependency should be monitored because it is a critical external journey.  
**Class:** monitor-only / monthly allowance.  
**Recommended action:** non-transactional reachability check only; never submit test patient/payment data without authorization.
